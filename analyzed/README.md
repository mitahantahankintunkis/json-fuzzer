# Parsing mismatches

The table in [./value_access_discrepancies.csv](./value_access_discrepancies.csv) contains JSON objects which are parsed differently between two JSON parsers. These objects can be used to for example bypass input validation as seen in [CVE-2017-12635](https://justi.cz/security/2017/11/14/couchdb-rce-npm.html).
